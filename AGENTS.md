# Project Rules

## Document Every Code Update, Feature, and Bug Fix

Every time code is updated, a new feature is added, or a bug is fixed in this project, create a markdown document in `docs/changes/` (for example, `docs/changes/YYYY-MM-DD_short-topic.md`).

Write the document in **simple, plain words** that are easy to understand, and always include:

1. **When** — The date and context of when the change or issue happened.
2. **Why** — Why the update, new feature, or fix was needed.
3. **How it happened** — How the bug occurred or how the feature/update came about.
4. **Solution** — What was done to fix or implement it, and which files were changed.
